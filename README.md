# FLAT 動画マニュアル（たたき台）

YouTube限定公開の動画に、手順（目次）・字幕・確認テストを付けて、スタッフがスマホで見られるようにする仕組みです。誰がどこまで見たかも記録します。字幕・手順・テストの下書きはGeminiで作ります。

```
gas/Code.gs        … Apps Script（スプレッドシートに付ける）
docs/index.html    … スタッフ用：マニュアル一覧
docs/view.html     … スタッフ用：動画＋手順＋字幕＋テスト
docs/admin.html    … 管理：新規作成（AIで下書き）・一覧
docs/edit.html     … 管理：手順・字幕・テストの編集、翻訳、公開
docs/progress.html … 管理：スタッフ×マニュアルの視聴状況
docs/config.js     … GASのURLを書くところ
```

## セットアップ

### 1. スプレッドシートとGAS
1. マニュアル用のGoogleアカウントで、新しいスプレッドシートを作る
2. 「拡張機能」→「Apps Script」を開き、`gas/Code.gs` の中身を全部貼り付けて保存
3. 「プロジェクトの設定」→「スクリプト プロパティ」に次を追加
   - `ADMIN_KEY`：管理画面のパスワード（好きな文字列）
   - `GEMINI_API_KEY`：[Google AI Studio](https://aistudio.google.com/) で作ったAPIキー
   - `GEMINI_MODEL`：（任意）モデル名。省略すると `gemini-3.6-flash`
4. エディタで関数 `setup` を選んで「実行」→ 権限を許可。シートが7つ作られます
5. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
   - 表示されたURL（`.../exec`）をコピー

> Code.gs を書き換えたときは「デプロイを管理」→ 鉛筆 →「新バージョン」で更新します（URLは変わりません）。

### 2. 画面（GitHub Pages）
1. `docs/config.js` の `GAS_URL` を、さっきのURLに書き換える
2. リポジトリの Settings → Pages で、ブランチ `main`・フォルダ `/docs` を選ぶ
3. 表示されたURLを開くと一覧画面。`admin.html` が管理画面です

### 3. スタッフの登録
スプレッドシートの `staff` シートに名前を入れます（`active` を FALSE にすると一覧から消えます）。テスト用に2人入っています。

## 使い方

1. YouTubeアプリで、マニュアル用チャンネルに動画を **限定公開** で上げる
2. `admin.html` →「新しいマニュアルを作る」
   - YouTubeのURL、同じ動画のファイルを選ぶ
   - 字幕の作り方を選ぶ：話しながら撮った／無言＋メモ／アフレコ
   - 「AIで下書きを作る」→ 1〜3分ほどで編集画面が開く
3. 編集画面で、手順・字幕・テストを直す
   - 動画を見ながら「今」ボタンで時間を合わせられます
   - 「日本語から翻訳する」で英語・ベトナム語を作れます（言語は Code.gs の `LANGS` で変更）
4. 「公開する」にチェックして保存 → スタッフの一覧に出ます
5. `progress.html` で、誰がどこまで見たかを確認

## 字幕の作り方（3種類）
| 作り方 | 中身 | 向いている場面 |
| --- | --- | --- |
| 話しながら撮った | 動画の声を字幕にする | 新人に教えている場面 |
| 無言＋メモ | 映像とメモを照らし合わせる | 一人で撮るとき |
| アフレコ | 動画を見ながら録音した声を字幕にする（録音は再生しない） | あとから説明を足すとき |

使わない作り方は、`admin.html` の選択肢（`newMode`）から外せば消せます。

## 注意点（たたき台なので）
- **Geminiの無料枠**：送った動画や文章がGoogleの製品改善に使われることがあります。配合など社外秘は入れないでください。上限に当たると「回数上限」のエラーが出ます
- **モデル名**：Geminiのモデルはよく入れ替わります。エラーになったら `GEMINI_MODEL` を新しい名前に変えてください
- **動画の大きさ**：720p・5分以内がおすすめ。大きいほどアップロードとAIの処理に時間がかかります
- **見る側の認証なし**：今はURLを知っていれば公開中のマニュアルを読めます。LIFFに載せるときに、LINEのIDでの確認を足す予定
- **テストは日本語のみ**（翻訳は手順と字幕だけ）
- **「見られた回数」**は手順の番号で数えているので、手順を足したり消したりすると、前の数字とずれます
