投稿のしかた

マニュアルを作る人（管理者・店舗責任者）向けの説明です。

撮る・写真を選ぶ→AIで下書き→直す→公開（責任者は申請）
🎬 動画のマニュアルを作る 📷 写真・レシピのマニュアルを作る 📄 スプレッドシートからまとめて取り込む（管理者） 撮影のコツ 下書きを直す 公開するまでの流れ 店舗・フォルダ・タグ 気をつけること 困ったとき

🎬 動画のマニュアルを作る

  1. スマホで作業を撮る（1本＝1つの作業、3分前後が目安）
  2. 管理画面の「新しいマニュアルを作る」で 「🎬 動画」 を選ぶ
  3. タイトル（空ならAIが付けます）・店舗・フォルダ・タグを入れる
  4. 「動画ファイル」で撮った動画を選ぶ
  5. 「字幕の作り方」を選ぶ
    • 話しながら撮った：動画の声を字幕にします
    • 無言で撮った：映像と「作業メモ」から字幕を作ります。コツや温度・時間はメモに書いてください
    • アフレコ：「録音しながら再生」を押し、動画を見ながら説明を吹き込みます
  6. 「AIで下書きを作る」を押す
動画を送り終わるまでは画面を開いたままにしてください。「受け付けました」と出たら閉じて大丈夫です。下書きができるとLINEでお知らせが届きます。

YouTubeのURLについて

  • YouTubeに上げていなければ、URLは空のままでOKです。動画は管理者のGoogleドライブに保存され、管理者がYouTubeに上げます
  • 自分で上げる場合は、「FLAT マニュアル」チャンネルに切り替えて、必ず 「限定公開」 にしてください

📷 写真・レシピのマニュアルを作る

レシピ・ドリンクの作り方・片付け・機械の分解など、写真と文章で伝えたいものはこちら。

  1. 「新しいマニュアルを作る」で 「📷 写真・レシピ」 を選ぶ
  2. 写真を選ぶ（何枚でも。1枚目が表紙になります。作業の順番に選ぶとAIが手順に合わせやすいです）
  3. メモ欄に、材料・分量・手順などを書く。Talknoteの投稿をそのままコピーして貼り付けてもOK
  4. どちらかを押す
    • AIで下書きを作る：材料表・写真付きの手順・補足・タグ・確認テストをAIが作ります（できたらLINEでお知らせ）
    • AIを使わずに作る：写真を手順に並べ、メモを補足に入れた下書きをすぐ作ります。あとは手で直します
分量は「1000」「1.5」のように数字だけにしておくと、スタッフの画面で「できあがりの数」を変えたときに自動で計算し直されます。「適量」などの文字はそのまま表示されます。

📄 スプレッドシートからまとめて取り込む（管理者）

写真を貼ったレシピのスプレッドシート（例：サンドレシピ）を、シートごとに1品として取り込みます。

  1. 管理画面の「スプレッドシートから取り込む」にURLを貼り、「シートを読み込む」
  2. 取り込むシートにチェック（写真のないシートは最初から外れています）
  3. 店舗・フォルダ・共通のタグを選んで「選んだシートを取り込む」
  • 写真はシートの上から順に手順として並びます（1品あたり12枚まで）
  • 写真に書き込まれた文字やセルの文字も、AIが読み取って手順・材料にします
  • シート名がタイトルになり、すべて「下書き」で保存されます。できたものからLINEでお知らせします
  • 品数が多いと全部できるまで数十分かかります。画面は閉じて大丈夫です
写真の文字は読み間違えることがあります。サイズ・分量・順番は必ず確認してから公開してください。

撮影のコツ

  • 横向きで、手元がよく見える位置から撮る
  • 1人で撮るときは、首掛けのスマホホルダーやクリップ式スタンドがあると両手が空きます
  • 新人に教えている場面を、もう1人がそのまま撮るのもおすすめです
  • 完璧に撮ろうとしなくて大丈夫。字幕や区切りはAIが手伝います
  • レシピの写真は、明るい場所で、材料や手元が分かるように撮る

下書きを直す

管理画面の一覧か、LINEの「編集する」ボタンから開きます。

動画のとき

  • 手順：動画を見ながら「今」ボタンで開始時間を合わせ、見出しと説明を直す
  • 字幕：行をタップして文字を直す。「今」で開始・終了の時間を合わせる
  • 翻訳：日本語を直してから「日本語から翻訳する」を押す

写真・レシピのとき

  • 材料：グループ（生地・折り込みなど）・材料・分量・単位・メモを直す
  • 手順：↑↓で並べ替え、写真を付ける・変える・外す、「表紙にする」
  • 表紙と分量：表紙の写真、できあがりの数（例：20 個分）、補足

共通

  • テスト：大事なポイントを2〜3問。選択肢は1行に1つ
  • 途中保存は編集を続けるとき、保存して戻るは終わったとき
  • 「表示を確認」で、スタッフからどう見えるか確かめられます

公開するまでの流れ

店舗責任者

下書きを直す→「公開を申請する」→管理者が確認→公開 or 差し戻し
  • 結果はLINEで届きます。差し戻されたら理由を見て直し、もう一度申請してください
  • 公開中のマニュアルを直したときは、公開したまま管理者に通知が届きます
  • 作成・編集できるのは、自分の店舗と「共通」のマニュアルだけです

管理者

  • 申請が来るとLINEに「確認する」ボタン付きで届きます。編集画面の「確認して公開する」か、理由を書いて「差し戻す」
  • 動画のマニュアルは、YouTubeのURLが入っていないと公開できません。ドライブにある動画は「ドライブの動画を開く」から保存してYouTubeに上げ、URLを入れて保存してください（ドライブの動画は自動でゴミ箱に移ります）

店舗・フォルダ・タグ

  • 店舗：その店だけの手順なら店舗名、どの店でも同じなら「共通」
  • フォルダ：パン製造・片付け・清掃・機械・ドリンクなど。リストにないものは名前を入れれば新しく作れます。似た名前のフォルダを増やさないよう、まず今あるものから選んでください
  • タグ：商品名・作業名・道具の名前など。#クロワッサン #成形 のようにスペースで区切ります。スタッフはタグで検索できます

気をつけること

AIの下書きには間違いが入ることがあります。特に分量・温度・時間は必ず自分の目で確認してから公開・申請してください。
  • AIの下書き作りには、Googleの無料のAI（Gemini）を使っています。送った動画・写真・文章がGoogleの改善に使われることがあります
  • お客さんや他のスタッフの顔が大きく映る写真・動画は避けてください
  • 同じ作業のマニュアルがすでにないか、スタッフの一覧で検索してから作ると重複を防げます

困ったとき

  • 画面がおかしい・ボタンがない：再読み込み（パソコンは Ctrl+F5）を試してください
  • 「回数上限」と出た：AIの無料枠の上限です。少し時間をおいてから試してください
  • 下書きのお知らせが来ない：管理画面の一覧で「作成中」「エラー」になっていないか確認してください
  • エラーが出た：エラーのメッセージが入るようにスクリーンショットを撮って、管理者に送ってください
